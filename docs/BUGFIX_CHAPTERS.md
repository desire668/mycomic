## 结论

1. 每本漫画的章节集合均来自该漫画详情页自身的 `x-data` 数组，互不共享。
2. 章节 ID 与漫画一一对应；点击章节后打开的章节页图片全部属于该章节。
3. 站点「最近更新」侧栏中的其他漫画章节不会再被解析为当前漫画的章节。
4. 章节极少的漫画（如 50676 仅 1 话）也不会回落到全站章节链接。
